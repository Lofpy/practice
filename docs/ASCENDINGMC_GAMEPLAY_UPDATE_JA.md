# AscendingMC Practice ゲームプレイ更新

## 試合終了

- 約3秒の結果表示中、移動・視点操作ができます。攻撃、アイテム使用、ドロップは引き続き禁止です。
- 致死ダメージを通常の死亡処理へ通し、倒れるアニメーションを表示します。プレイヤーは約1秒後に死亡地点で自動リスポーンし、残りの結果表示時間は移動できます。
- Boxingはヒット数で決着するため、HPによる死亡処理は行いません。
- アリーナを解放するときに、そのアリーナの範囲内の落下アイテムを削除します。ロビー・別アリーナのアイテムやプレイヤーは対象外です。範囲は現行100×150のアリーナ配置に対応しています。
- Duelでは試合中のELO欄と試合結果のレート変動を表示しません。レーティング更新は引き続きRankedのみです。

## Bot

- 全Kitで、接敵前から後退するのではなく前進して攻撃します。短い間隔で2回連続の有効ヒットが成立してから間合いを調整し、被弾や飲食・補充時にはそのコンボ状態を解除します。
- NoDebuffは常時Speed IIを廃止し、Kit内の有限のポーションを飲みます。効果がない／間もなく切れる場合に飲み直します。飲用には通常の32tickを使い、回復が必要な場合は中断します。
- NoDebuff・ComboのBotは金ニンジンを食べません。Botのみ満腹を維持してダッシュ不能を防ぎます。人間プレイヤーの空腹・食事と、Comboの回復用上位金リンゴの使用は変更しません。
- ホットバーの回復ポーションを使い切ると、後方へ逃げながらジャンプして10tick（約0.5秒）の補充動作を行い、インベントリの実在庫をホットバーへ移します。在庫全体がゼロなら補充しません。
- 通常の戦闘移動・クリティカルのために能動的なジャンプはしません。ジャンプ追加は上記の補充動作に限ります。
- 回復ポーションは現物在庫を消費します。設定数がKitの在庫数を超えても、余分なアイテムは作成しません。
- 認定戦と初期設定で、Botのポーションがプレイヤーも回復します。通常Botの設定項目 `bot.healing.can-heal-opponent` は残っています。既存コンフィグの明示的な `false` は上書きしないため、有効にするにはGUIまたは設定から変更してください。

## 認定戦の緩和（fixed-balanced-v2）

- 認定Botの攻撃頻度を16.8～19.2 CPSから10～13 CPS、リーチを3.0から2.8ブロック、回復再使用間隔を18から24tickに変更します。
- 接敵時の照準追従・予測を弱めます。近接戦で相手の正面を向く挙動、少ない横移動とコンボ成立後の前後移動は維持します。
- 総合評価は従来の加重平均を1.20倍し、100点を上限にします。実測値は変更しません。各Kitの認定3戦、初期ELO 1500.000～1800.000、最低ELO 1400.000、K=32、マッチ差100以内は維持します。
- 保存済みの認定結果・ELOは変更せず、新しい認定戦だけに適用します。途中の認定は旧スコアもそのまま3戦平均に含みます。通常Botの強さ設定は変更しません。

## 表示・言語

- ネットワークの表示名は **AscendingMC**、PvPの表示は **Practice**。メニュー等は赤を基調とします。
- PracticeロビーのSettings、または `/settings` で **日本語 / English** を切り替えます。初期値は日本語です。
- 一般プレイヤー向けのメニュー・案内・対戦結果を切り替えます。PvPサーバーのスコアボードタイトルは赤・太字の **Practice**、項目は常に英語です。接続ロビーのネットワーク名 **AscendingMC** は維持します。Kit ID、コマンド構文、管理者向け診断ログは翻訳しません。
- 言語はプレイヤーUUIDごとに `cosmetic-preferences.yml` の `locale: ja` / `locale: en` として保存されます。本リリースには別途開発中のDB・Web同期機能は含めません。
- 既存の保存データ・連携を壊さないため、内部プラグイン名、Javaパッケージ、JARファイル名、`poppypractice.*` 権限、プロキシ接続先ID `pvp` は変更しません。
- プロキシ／ネットワークロビーの新しいMOTDはテンプレートに反映しています。GCP起動時に旧デフォルトの表示名だけを移行し、既存サーバーの独自設定は維持します。

## 観戦

- `/spec <プレイヤー名>` または `/spectate <プレイヤー名>` で、指定プレイヤーの通常対戦／Duel／Bot戦／認定戦を観戦します。
- ロビーでキューに入っていないときのみ開始できます。観戦開始はカウントダウン中または対戦中に限り、開始済みの観戦は結果表示の3秒間も継続します。
- `/spec`、`/spec leave`、`/spawn` で退出します。試合の終了、対象の退出、プラグイン停止でも後片付けします。
- 権限は `poppypractice.spec`（デフォルト全員有効）。権限を途中で失っても退出は可能です。
- 1.7.10向けにも使えるAdventure＋飛行＋非表示方式です。観戦者による攻撃、被弾、衝突、アイテム拾得・使用、ブロック変更、投擲への干渉を防止します。
- 別ワールドや観戦範囲外への移動を禁止し、対象が次の試合へ移っても自動では追従しません。

## 反映時の注意

この更新では既存のワールド、認定結果、ELO、キット配置の削除は行いません。ソースのビルドとテスト完了後、PracticeとネットワークロビーのJAR・必要な表示設定を別途反映してください。実クライアントでのアニメーションと1.7.10／1.8.9以降の観戦表示は実機確認が必要です。
